What are these?

These are the firmware builds for the MeshCore repeater + observer setup for Finland with sane defaults. They allow two major use cases

  • Repeater that also acts as an observer, uploading packets via MQTT, removing the need for an extra observer node
  • Observer that never transmits, only receives and uploads to MQTT, good for "super sniffers" that cannot transmit

By default these upload all received packets to letsmesh analyzer targets. If you want to upload to CoreScope, contact Vaizki on Discord for integration details.

How to use these artifacts

  • Choose your row by env base name.
  • Open info.txt first to verify applied flags and notes.
  • Use normal firmware for regular updates; use merged firmware when full flash layout update is required.

Differences from stock repeater firmware

  • Source and instructions at Vaizki's MeshCore fork on GitHub
  • Based on agessaman's repeater-observer firmware that provides MQTT bridging, massive thanks to him!
  • Receive-only mode on by default when flashed to new device
  • EU Narrow style parameters: 869.6179809 MHz, 62.5 kHz, SF8, CR8 with AF 9 (10% duty-cycle)

Steps to get it working

  1. Save your current private key before flashing!
  2. Flash the firmware to your device (first time use the merged firmware)
  3. Connect to the device console via serial (115200 baud) or repeater login
  4. Set the device name and IATA/location code
  5. Set lat & lon to get on the map
  6. Set the hash path mode to 1 for 2-byte IDs if in HEL region
  7. Set the WiFi credentials
  8. Reboot the device
  9. Verify the device is connected to WiFi and MQTT
  10. Verify the device is receiving packets from the mesh and uploading to MQTT
  11. Enable TX and repeat (forwarding) if you are setting up a repeater
  12. Reboot for MQTT settings to take effect

Example commands for a repeater

  
    set prv.key <your_64_hex_char_private_key>
    set name Banaanisatama-Repeater
    set path.hash.mode 1
    set mqtt.iata HEL
    set lat 60.1
    set lon 24.9
    set wifi.ssid my-wifi-ssid
    set wifi.pwd my-wifi-password
    set mqtt.rx on
    set mqtt.tx on
    set radio.tx on
    set repeat on
    reboot

After the repeater is running, good to advert once to get on the map.

    
      advert.flood

Example commands for an invisible & silent observer

    
      set prv.key <your_64_hex_char_private_key>
      set name Banaanisatama-Observer
      set path.hash.mode 1
      set mqtt.iata HEL
      set wifi.ssid my-wifi-ssid
      set wifi.pwd my-wifi-password
      set mqtt.rx on
      set mqtt.tx off
      set radio.tx off
      reboot
